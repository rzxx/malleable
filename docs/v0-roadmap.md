# V0 Roadmap

## 1. Local Shell

Show realms and capsules from the daemon.

## 2. Capsule Runtime

Validate manifests, launch capsules, and show logs/source paths.

## 3. Template Creation

Create a capsule from a tiny starter template.

## 4. Mutation Loop

Edit a capsule, refresh it, and keep the artifact local.

## 5. Agent Workbench

Generate and patch capsules inside clear filesystem boundaries.

## 6. Packaging

Wrap the environment as a desktop app. Build a Linux image only after the shell is useful.
